# Experimental Results

This folder contains the experimental results generated during the training and evaluation of the machine-learning models developed for the **STADIOalot Return Prediction** project.

The results provide quantitative performance measurements for the two classification models used to predict whether an e-commerce order will be returned:

* **Model 1 — Random Forest Classifier**
* **Model 2 — XGBoost Classifier**

The folder also contains the statistical comparison results generated, where the two trained models are evaluated on the same test observations.

Both models are developed using the feature-engineered dataset:

```text
data/processed/returns_features.csv
```

The models use the same target variable and a stratified 80/20 train/test split with `random_state=42` to support consistent and reproducible evaluation.

---

The `experimental_results` folder contains the evaluation results generated by the modelling and model-comparison notebooks.

# Bootstrap Confidence Intervals

Bootstrap resampling is used to estimate the uncertainty associated with the observed model performance.

A total of:

```text
1,000 bootstrap samples
```

are generated using:

```text
random_state = 42
```

The confidence level is:

```text
95%
```

The 2.5th and 97.5th percentiles of the bootstrap distributions are used as the lower and upper confidence interval limits.

Bootstrap confidence intervals are calculated for:

* Accuracy
* Precision
* Recall
* F1-score
* ROC-AUC

The individual model bootstrap results are stored in:

```text
experimental_results/model1_bootstrap_confidence_intervals.csv
```

and:

```text
experimental_results/model2_bootstrap_confidence_intervals.csv
```

---

# Paired Bootstrap Model Comparison

A paired bootstrap analysis is also performed.

The same bootstrap test observations are used for both models in each resampling iteration.

The difference is calculated as:

```text
Model 2 − Model 1
```

This provides a confidence interval for the observed difference between XGBoost and Random Forest for each performance metric.

The paired bootstrap results are stored together with the individual model confidence intervals in:

```text
experimental_results/model_comparison_bootstrap_confidence_intervals.csv
```

The comparison includes:

* Observed difference
* 95% confidence interval lower bound
* 95% confidence interval upper bound
* Number of bootstrap samples
* Whether the confidence interval includes zero
* Interpretation of the confidence interval

If the confidence interval includes zero, the bootstrap analysis does not provide clear evidence of a difference for that metric at the 95% confidence level.

# McNemar's Test

McNemar's test is used to compare the paired classification errors of the two models.

The test is appropriate because both models make predictions on the **same test observations**.

The paired outcomes are grouped into:

1. Both models correctly classify the observation.
2. Model 1 is correct and Model 2 is incorrect.
3. Model 1 is incorrect and Model 2 is correct.
4. Both models are incorrect.

The significance level is:

```text
alpha = 0.05
```

The hypotheses are:

```text
H0: There is no statistically significant difference
    between the paired classification error patterns.

H1: There is a statistically significant difference
    between the paired classification error patterns.
```

The McNemar test results are saved to:

```text
experimental_results/mcnemar_test.csv
```

The file contains:

* Paired classification counts
* Test statistic
* p-value
* Significance level
* Statistical decision

The p-value is interpreted using the predefined significance level of `0.05`.

# Metrics Stored in the Results Files

The individual model metric files contain the following performance measures:

| Metric      | Description                                                                          |
| ----------- | ------------------------------------------------------------------------------------ |
| `model`     | Name of the machine-learning model                                                   |
| `accuracy`  | Proportion of all test predictions classified correctly                              |
| `precision` | Proportion of predicted returned orders that were actually returned                  |
| `recall`    | Proportion of actual returned orders correctly identified                            |
| `f1_score`  | Harmonic mean of precision and recall                                                |
| `roc_auc`   | Measures the model's ability to distinguish between returned and non-returned orders |

These metrics provide different perspectives on classification performance rather than relying on accuracy alone.

# Purpose of the Experimental Results

The files in this folder provide a persistent record of the quantitative results generated during model development and evaluation.

They are used to:

* document the performance of each predictive model;
* provide the metric values required for model evaluation;
* support statistical evaluation of model performance;
* compare the Random Forest and XGBoost approaches;
* document uncertainty using bootstrap confidence intervals;
* evaluate paired classification differences using McNemar's test;
* provide numerical evidence for the findings presented in the final project report.

The experimental results should be considered together with the trained model files, notebooks, statistical outputs, and confusion-matrix visualisations.
