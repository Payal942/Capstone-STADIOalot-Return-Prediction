# Experimental Results

This folder contains the experimental results generated during the training and evaluation of the machine-learning models developed for the **STADIOalot Return Prediction** project.

The results provide the quantitative performance measurements for the two classification models used to predict whether an e-commerce order will be returned:

* **Model 1 — Random Forest Classifier**
* **Model 2 — XGBoost Classifier**

Both models are trained using the feature-engineered dataset:

```text
data/processed/returns_features.csv
```

The models use the same target variable, preprocessing approach and stratified 80/20 train/test split to support a consistent evaluation.

---

## Contents

This folder contains the evaluation metrics generated by the modelling notebooks.

| File                               | Model         | Purpose                           |
| ---------------------------------- | ------------- | --------------------------------- |
| `model1_random_forest_metrics.csv` | Random Forest | Stores Model 1 evaluation metrics |
| `model2_xgboost_metrics.csv`       | XGBoost       | Stores Model 2 evaluation metrics |

The CSV files contain the calculated performance measures obtained from the test dataset.

## Experimental Evaluation Process

Both models follow the same general evaluation process.

```text
Feature-Engineered Dataset
        │
        ▼
returns_features.csv
        │
        ▼
Separate Features (X)
and Target (y)
        │
        ▼
Stratified 80/20 Train/Test Split
        │
        ├─────────────────────┐
        ▼                     ▼
Random Forest             XGBoost
   Model 1                  Model 2
        │                     │
        ▼                     ▼
Predictions + Return Probabilities
        │                     │
        └──────────┬──────────┘
                   ▼
            Model Evaluation
                   │
        ┌──────────┼──────────┐
        ▼          ▼          ▼
     Accuracy   Precision    Recall
        │          │          │
        └──────┬───┴──────┬───┘
               ▼          ▼
            F1-score    ROC-AUC
               │
               ▼
       Saved Evaluation Results
```

The test set is kept separate from the training process and is used to measure how well each trained model performs on previously unseen data.

## Metrics Stored in the Results Files

Each model's metrics CSV contains the following fields:

| Metric      | Description                                                                          |
| ----------- | ------------------------------------------------------------------------------------ |
| `model`     | Name of the machine-learning model                                                   |
| `accuracy`  | Proportion of all test predictions classified correctly                              |
| `precision` | Proportion of predicted returned orders that were actually returned                  |
| `recall`    | Proportion of actual returned orders correctly identified                            |
| `f1_score`  | Harmonic mean of precision and recall                                                |
| `roc_auc`   | Measures the model's ability to distinguish between returned and non-returned orders |

These metrics provide different perspectives on classification performance rather than relying on accuracy alone.

## Purpose of the Experimental Results

The files in this folder provide a persistent record of the evaluation results generated during model development.

They are used to:

* document the performance of each predictive model;
* support analysis of model performance;
* provide the metric values required for model evaluation;
* support the comparison of the Random Forest and XGBoost approaches;
* provide evidence for the findings presented in the final project report.

The experimental results should be considered together with the confusion-matrix visualisations and classification reports generated by the respective modelling notebooks.
