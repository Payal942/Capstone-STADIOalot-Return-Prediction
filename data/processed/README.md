# Processed Data

This folder contains datasets that have been cleaned, transformed and prepared for feature engineering and machine learning as part of the **STADIOalot Return Prediction** project.

All processed datasets are derived from the original raw dataset stored in `data/raw/` and are generated through the project notebooks.

## Contents

### 1. `returns_preprocessed.csv`

**Source:** `data/raw/ecommerce_returns_synthetic_data.csv`

This dataset is generated by **Notebook 1 — Data Preprocessing**.

The preprocessing includes:

* Standardising column names
* Inspecting and handling missing values
* Detecting and removing duplicate records
* Preparing the target variable
* Encoding `Return_Status`

  * `Returned = 1`
  * `Not Returned = 0`
* Converting applicable date columns
* Identifying and removing data leakage
* Checking numeric data quality
* Handling invalid negative numeric values
* Removing records with missing target values
* Performing final validation

**Output:** `data/processed/returns_preprocessed.csv`

---

### 2. `returns_features.csv`

**Source:** `data/processed/returns_preprocessed.csv`

This dataset is generated by **Notebook 2 — Feature Engineering**.

The feature engineering includes:

* Creating temporal features from `Order_Date`

  * `order_year`
  * `order_month`
  * `order_day`
  * `order_day_of_week`
  * `order_week_of_year`
  * `order_is_weekend`
* Creating commercial features

  * `order_gross_value`
  * `discount_fraction`
  * `discount_amount_est`
* Creating customer age bands

  * `<18`
  * `18-24`
  * `25-34`
  * `35-44`
  * `45-54`
  * `55-64`
  * `65+`
* Removing identifier columns that do not provide generalisable predictive information
* Validating the target variable
* Performing final feature and missing-value checks
* Preparing the final dataset for machine learning modelling

**Output:** `data/processed/returns_features.csv`

## Data Handling

The original raw dataset is preserved in `data/raw/` and is not modified directly.

The processed datasets are generated as separate outputs so that each stage of the data preparation workflow can be reproduced and traced back to its source.

The final `returns_features.csv` dataset is used as the input for the machine learning modelling stage of the **STADIOalot Return Prediction** project.
