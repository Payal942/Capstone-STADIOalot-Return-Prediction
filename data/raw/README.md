# Raw Data

This folder contains the original datasets received or obtained for the STADIOalot Return Prediction project.

Raw datasets should be preserved in their original form and should not be modified directly. Any cleaning, transformation or preprocessing should be performed on copies of the data and stored in the `data/processed/` folder.

## Contents

- Original client-provided datasets
- Publicly available datasets used for the project, where applicable
- Other unmodified source data required for the analysis
